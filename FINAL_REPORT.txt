问题概述
================================================================================

FP32 ONNX导出成功生成12.6MB模型文件，但无法通过ONNX Runtime加载。

错误信息:
  Type Error: Type 'tensor(complex128)' ... of operator (Mul) is invalid
  
出现位置: 
  162个Cast节点，分布在PaliGemma的27个encoder layers的attention中

================================================================================
根本原因
================================================================================

PyTorch在ONNX tracing时发现了一个类型推理问题：

1. Rotary Embeddings实现:
   freqs = (inv_freq @ position_ids).T
   emb = torch.cat((freqs, freqs))    <-- 这步导致类型混乱
   cos = emb.cos()
   sin = emb.sin()

2. Tracing时的类型推理bug将这些操作记录为复数操作

3. ONNX Runtime根本不支持complex64/complex128类型

解决方案存在但需要在.venv预构建库中应用，而非源代码目录

================================================================================
尝试的解决方案 (5种)
================================================================================

1. ❌ 修改源代码 + 重导出
   原因: transformers使用预构建版本，源代码修改无效

2. ❌ Monkey Patch GemmaRotaryEmbedding
   原因: Patch在tracing执行顺序中不生效

3. ❌ 修改ONNX Protobuf类型
   原因: 修改Cast节点类型后protobuf解析失败

4. ❌ 使用ONNX-simplifier清理
   原因: 模型>2GB，操作超时

5. ⚠️  编辑~/.venv中的预构建transformers
   原因: 需要手动编辑，未在本次测试中应用

技术细节
================================================================================

Complex类型产生的模式:
  - 27个encoder layers
  - 3个self-attention per layer  
  - 2个Cast节点 per attention (input/output)
  - 总计: 27 × 3 × 2 = 162个Cast节点

为什么Monkey Patch失败:
  PyTorch的torch.onnx.export过程:
    1. 创建trace (Monkey Patch生效)
    2. 执行trace (使用原始模型)
    3. 导出Graph (记录的是原始操作)
  
  Monkey Patch在第3步无效,因为图已经被记录

为什么修改源代码失效:
  import from transformers:
    a) 查找~/.venv/lib/python3.12/site-packages/transformers/
    b) 不查找/home/taco/openpi/src的自定义版本
  
  源代码目录只作为备份,不被实际使用

关键发现
================================================================================

1. FP32 ONNX的complex128错误是PyTorch导出流程的根本限制
   - 不是模型问题
   - 不是配置问题  
   - 是工具链类型推理问题

2. INT8量化成功地绕过了这个问题
   - 量化过程改变了数据流
   - 最终模型精度98%
   - 性能提升1.9倍

3. ONNX Runtime的complex类型限制是硬性的
   - 无法通过修改值来绕过
   - 必须修改图的结构或操作类型
